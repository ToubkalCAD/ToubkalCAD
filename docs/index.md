## Browser CAD, openly developed

ToubkalCAD brings an OpenCascade geometry kernel, a feature-based modeling
workflow, and a modern 3D interface to the web. It is under active development,
so the documentation describes both the workflows available today and the
limitations you should expect.

::: tip Ready to model?
[Launch ToubkalCAD](https://toubkal-cad.vercel.app), wait for the OpenCascade
status indicator to become ready, and follow [Create Your First Model](/getting-started/first-model).
:::
