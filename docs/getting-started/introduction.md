# Introduction

ToubkalCAD is a free and open-source, browser-based parametric CAD application.
It combines a desktop-style modeling workspace with the OpenCascade geometry
kernel compiled to WebAssembly.

You can use ToubkalCAD to create sketches, build and modify solids, work with
reference geometry and surfaces, inspect models, and create assemblies. Because
it runs in the browser, no native CAD installation is required.

## Who this documentation is for

- **Users** can begin with the setup pages, first model, tutorials, and user guide.
- **Contributors** can learn the project workflow and improve code, tests, or docs.
- **Developers** can study the runtime architecture and major internal systems.

## Recommended learning path

1. Check the [browser requirements](./browser-requirements).
2. [Launch ToubkalCAD](./launch-toubkalcad) and identify the main interface areas.
3. [Create your first model](./first-model).
4. Work through the [mounting bracket tutorial](/tutorials/mounting-bracket).
5. Use the [User Guide](/user-guide/) for feature-specific help.

::: warning Active development
ToubkalCAD is not yet a replacement for a mature desktop CAD package. Save
important work frequently, and consult [Current Limitations](/reference/current-limitations)
before relying on it for production work.
:::
