# Create Your First Model

This exercise creates a box, changes its position, and inspects the result. It
introduces the same selection-and-properties pattern used throughout ToubkalCAD.

## 1. Start a blank document

[Open ToubkalCAD](https://toubkal-cad.vercel.app), wait until OpenCascade is
ready, and create a blank document.

## 2. Create a box

1. Open the **Model** ribbon tab.
2. In **Primitives**, choose **Box**.
3. Enter the requested length, width, and height.
4. Confirm the command.

The new solid appears in both the viewport and model tree.

## 3. Inspect and move it

1. Select the box in the model tree.
2. Open the **Transform** properties.
3. Change a position value, or use the transform gizmo in the viewport.
4. Open **Material** to adjust its appearance.
5. Open **Analysis** or **Measure** to inspect geometric information.

Use <kbd>Shift</kbd>+<kbd>F</kbd> to fit the complete model in view. Press
<kbd>0</kbd> for perspective view or <kbd>5</kbd> for an isometric view.

## 4. Save the project

Choose **File → Save Project** or press <kbd>Ctrl</kbd>+<kbd>S</kbd>. Keep the
downloaded file so you can open the model again later.
