# Status and Roadmap

ToubkalCAD is an active open-source project. Current development spans sketching,
parametric modeling, reference geometry, surfaces, assemblies, file
interoperability, appearance, analysis, and reliability.

## Follow current work

- [GitHub repository](https://github.com/ToubkalCAD/ToubkalCAD)
- [Issues](https://github.com/ToubkalCAD/ToubkalCAD/issues)
- [Roadmap design notes](https://github.com/ToubkalCAD/ToubkalCAD/blob/main/docs/ROADMAP.md)

The design notes are useful technical context, but they are not a release
promise. The repository history and working application are the authoritative
record of implemented behavior.

## How to help

Try the [live application](https://toubkal-cad.vercel.app), report a small and
reproducible issue, improve a documentation page, or follow the
[Contributor Guide](/contributing/) to propose code changes.
