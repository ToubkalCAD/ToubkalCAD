# Keyboard Shortcuts

## File and editing

| Action | Shortcut |
| --- | --- |
| New project | <kbd>Ctrl</kbd>+<kbd>N</kbd> |
| Open project | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| Save project | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| Undo | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd>+<kbd>Y</kbd> |
| Select all | <kbd>Ctrl</kbd>+<kbd>A</kbd> |
| Cancel active tool | <kbd>Esc</kbd> |
| Delete selection | <kbd>Delete</kbd> |

## View and objects

| Action | Shortcut |
| --- | --- |
| Perspective view | <kbd>0</kbd> |
| Top view | <kbd>7</kbd> |
| Front view | <kbd>1</kbd> |
| Right view | <kbd>3</kbd> |
| Isometric view | <kbd>5</kbd> |
| Frame selected | <kbd>F</kbd> |
| Fit all | <kbd>Shift</kbd>+<kbd>F</kbd> |
| Hide/show selection | <kbd>H</kbd> |
| Duplicate selection | <kbd>Ctrl</kbd>+<kbd>D</kbd> |
| Translate mode | <kbd>W</kbd> |
| Rotate mode | <kbd>E</kbd> |
| Scale mode | <kbd>R</kbd> |

Some shortcuts do nothing when the current selection or active command does not
support the requested action.
