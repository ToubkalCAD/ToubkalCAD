# Troubleshooting

Start with the page that best matches the problem:

- [Startup and WebAssembly](./startup-and-wasm)
- [Current Limitations](/reference/current-limitations)

When reporting a bug, include the browser and operating system, the exact steps,
the expected and actual result, and the smallest project that reproduces it.
Screenshots and browser-console errors are often useful.

[Open an issue on GitHub](https://github.com/ToubkalCAD/ToubkalCAD/issues)
