# Viewport Navigation

Use the viewport to orbit around the model, pan across it, and inspect detail.
The view cube and keyboard presets provide repeatable orientations.

## View commands

| Action | Shortcut |
| --- | --- |
| Perspective view | <kbd>0</kbd> |
| Top view | <kbd>7</kbd> |
| Front view | <kbd>1</kbd> |
| Right view | <kbd>3</kbd> |
| Isometric view | <kbd>5</kbd> |
| Frame selected | <kbd>F</kbd> |
| Fit all | <kbd>Shift</kbd>+<kbd>F</kbd> |

## Transform modes

When the transform gizmo is active:

| Mode | Shortcut |
| --- | --- |
| Translate | <kbd>W</kbd> |
| Rotate | <kbd>E</kbd> |
| Scale | <kbd>R</kbd> |

Use camera presets before placing reference geometry or checking an alignment.
Use **Frame selected** when a small object is lost in a large assembly.
