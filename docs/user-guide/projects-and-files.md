# Projects and Files

ToubkalCAD project commands are available from the **File** menu.

## Start a new project

Choose **File → New** or press <kbd>Ctrl</kbd>+<kbd>N</kbd>. Save the current
project first if you need to keep it.

## Save a project

Choose **File → Save Project** or press <kbd>Ctrl</kbd>+<kbd>S</kbd>. The browser
downloads a project file containing the document state. Store it somewhere you
can find again.

## Open a project

Choose **File → Open Project** or press <kbd>Ctrl</kbd>+<kbd>O</kbd>, then select
a previously saved ToubkalCAD project.

Project data can evolve while the application is under active development.
Keep backups of important files and record which ToubkalCAD version created
them.

## Exchange geometry

The application provides import and export tools for supported CAD exchange
formats. Exported geometry is useful for transferring final shapes, but it may
not preserve the editable feature history of a ToubkalCAD project.
