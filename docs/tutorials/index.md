# Tutorials

Tutorials combine several ToubkalCAD tools into complete modeling workflows.
Follow them in order if you are new to parametric CAD.

## Available tutorial

### [Model a Mounting Bracket](./mounting-bracket)

Create a constrained base sketch, extrude it into a solid, add a mounting hole,
and finish the edges. This tutorial introduces the feature tree and the
importance of building operations in a deliberate order.

More tutorials will be added as workflows stabilize.
